# 🎨 UI/UX Design – Wireframing & Low-Fidelity Design

## 📌 Project Overview

This project focuses on creating wireframes and low-fidelity UI/UX designs using **Figma**.

The main objective was to plan the application's structure, layout, navigation, and user interactions before moving toward high-fidelity visual design.

The wireframes focus on usability, content organization, and user experience rather than colors and decorative elements.

## 🎯 Project Objectives

- Understand the fundamentals of UI/UX design.
- Create structured low-fidelity wireframes.
- Organize interface elements and content effectively.
- Design simple and intuitive navigation.
- Improve user experience through layout planning.
- Practice using Figma for digital wireframing.

## 🛠️ Tools Used

- **Figma:** Creating wireframes and designing interface layouts.
- **UI/UX Design Principles:** Applying usability, consistency, and visual hierarchy.
- **Wireframing:** Planning page structures and user interactions.

## ✨ Key Features

- Low-fidelity screen layouts.
- Simple and clean interface structure.
- Consistent navigation elements.
- Organized content sections.
- User-friendly page flow.
- Basic buttons, input fields, and interface elements.
